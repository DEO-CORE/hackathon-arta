# ARTA

Платформа повторного использования текстильных остатков.

- [`landing/`](landing/README.md) — React + Tailwind: лендинг и интерактивный демонстрационный интерфейс для хакатона.
- [`frontend/`](frontend/README.md) — существующий Flutter-клиент.
- [`backend/`](backend/README.md) — FastAPI, PostgreSQL, SQLAlchemy.
- [`docs/`](docs/) — API, дизайн и продуктовые материалы.

Быстрый запуск React-версии:

```sh
cd landing
npm ci
npm run dev
```

React-версия пока работает с локальными демо-данными. Инструкция по сценарию, тестам и интеграции находится в `landing/README.md`.
