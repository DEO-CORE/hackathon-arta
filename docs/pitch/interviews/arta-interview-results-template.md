# ARTA: шаблон результатов интервью (один экземпляр на одно интервью)

Дата подготовки: 2026-11-08. Владелец: business-analyst.

**Интервью проведено: 0 из 3–5 (на дату подготовки).**

Шаблон пуст. Ни одно поле не заполнено ответами. Копируйте блок «Интервью №» под каждого респондента, три таблицы держите раздельно. Вопросы и правила: `arta-interview-guide.md`.

Правила заполнения:
- ФАКТЫ: только числа, которые назвал респондент. Единица и период обязательны. «Видел в документах» = да, только если интервьюер лично увидел запись, накладную, чек или журнал.
- НАБЛЮДЕНИЯ: нечисловые заметки интервьюера (поведение, тон, обстановка, противоречия). Без чисел-оценок.
- ГИПОТЕЗЫ: утверждения для проверки. Запись в ГИПОТЕЗЫ не является результатом. Статус меняется только по правилу в колонках «подтвердит» и «опровергнет».
- Не переносить числа в финансовую модель, пока в группе не набрано не менее 3 интервью.
