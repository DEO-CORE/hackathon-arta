# Рыночные данные: открытые источники

Дата сбора: 2026-11-06 (открытый веб-поиск). Статус: черновик. Владелец: business-analyst (оркестратор внёс первую версию).

Метки: **verified** — официальный или первичный источник, дата указана; **secondary** — пересказ в СМИ, цифру надо сверить; **assumption / to-validate** — не подтверждено, в питч как факт не выносить.

Правило: ни одна цифра из этого файла не попадает в питч без метки и ссылки. Оценки по Бишкеку не переносятся на всю страну.
