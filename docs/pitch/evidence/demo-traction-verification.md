## 6. Готовность демо 45–60 секунд

Вердикт: **частично готово**. Живой показ возможен только для ядра «партия -> каталог -> заявка -> передача -> получение», и только при заранее поднятом сервере и подготовленных учётках. Остальное — запись или предзаготовленное состояние.

Предусловия для живого API-показа: запущены PostgreSQL и uvicorn на ноутбуке, телефон по USB, выполнен `adb reverse tcp:8000 tcp:8000`, сборка с `--dart-define=API_BASE_URL=http://127.0.0.1:8000 --dart-define=USE_DEMO_DATA=false`. Каждый пункт зависит от ноутбука и кабеля.
