# План проверки подтверждения email

Статус: ПЛАН. Ничего не выполнено. Дата: 2026-11-07. Владелец: QA. Источник: `docs/api.md` раздел 23 (предложение, одобрено оркестратором; на момент написания в разделе 23 демо-код и сроки помечены допущениями A23-n; при расхождении с реализацией приоритет у утверждённого решения, расхождение завести как вопрос).

Решения под проверку: код 6 цифр; демо-код `7777` только в демо; срок 10 минут; 5 неверных попыток, затем код аннулируется (блокировка 15 минут по A23-8); пауза между отправками 60 с; новая отправка аннулирует старый код; вход до подтверждения даёт `403 EMAIL_NOT_CONFIRMED` (только после верного пароля); недоступная отправка даёт 503 без «отправлено».

## Метки покрытия
- PT — pytest (пишет backend-engineer, `backend/tests/`; QA не пишет).
- WT — widget-тест Flutter (`frontend/test/`; существующий `verify_email_test.dart` — flutter-developer; дополнения QA — `email_verification_qa_test.dart`, только после отчётов flutter-developer и backend-engineer).
- DV — ручной прогон на телефоне (демо-сборка).
- NR — не проверяется (причина указана).

Статус каждого кейса: «не запускался» до прогона. PASS ставится только после фактического запуска теста либо касания на устройстве.

## 8. Риски
1. В production нет почтового провайдера: реальная отправка и доставка писем не проверяются (EV-P-16 NR); проверяются только контракт, адаптер-заглушка и 503. Включённое подтверждение в production без адаптера делает вход невозможным (сервис не должен стартовать, A23-5).
2. Демо-код 7777: утечка в production (флаг `DEMO_MODE` ошибочно включён, либо клиент показывает подсказку) обходит подтверждение владения почтой. Нужны EV-P-01, EV-P-15, EV-F-03; ручная проверка production невозможна без развёрнутого production-API.
3. Расхождение раздела 23 и реализации (сроки блокировки: «5 попыток» с 429 против аннулирования, формат кода 4/6 цифр в демо, код ошибки для 503, поведение навигации после успеха): часть ожидаемых результатов в плане предположительная; первый прогон может дать ложные FAIL до сверки с реализацией.
